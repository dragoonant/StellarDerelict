# Stellar Derelict

An original 3D corridor-tactics browser game by **evilgouki**. Five armoured Wardens board a dead ship, pull its
navigation core and fight their way back out through the Molt, an alien swarm that shows on the scanner only as pings
until someone lays eyes on it.

It is a spiritual successor to the classic armoured-squad-versus-alien-swarm board games: the premise is familiar, but
the setting, names, rules, numbers, missions and look are this project's own.

- Rules: `docs/spec/10-rules.md` · Mission 1: `docs/spec/11-mission-dead-reckoning.md` · Plan: `PLAN.md` · State: `STATUS.md`
- Run it: `npm install`, then `npm run dev`.
- Saves live in this browser only; a local server and the hosted page keep separate saves.
